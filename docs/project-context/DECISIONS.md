# ARCANUM — решения и рабочие предложения

Обновлено: 13 октября 2026.

## Последующее уточнение и реализация

Владелец попросил использовать материальную, малонасыщенную палитру Elden Ring: потускневшее золото, пергамент, уголь с оливковым подтоном, холодный камень, мох и сухую ржавчину. Это дополняет первоначальный чёрно-золотой концепт, сохраняя спокойный ритуал. Цвета в описании — художественная интерпретация, а не официальные значения игры.

Проводники: Странница — лунное серебро, Хранитель — латунь/мох, Искра — приглушённая медь. Исходные тёмные мох/камень/ржавчина используются для декора; для текста выбраны более светлые оттенки. Спецификация: `app/docs/ART_DIRECTION_PALETTE.md`.

Работа ведётся в `app/`, отдельном worktree ветки `codex/arcanum-redesign`. Созданы рабочий основной интерфейс и пять эталонных ассетов v001/v002. Укреплены идемпотентность, восстановление клиентского сеанса, атомарность выдачи доступа и deadline LLM. Полная колода, сохраняемый worker, правила fallback/квоты, история диалога в БД и платный релиз остаются последующими задачами.

С согласия владельца ключи загружены из локального env без раскрытия значений. Zen подтвердил 400 на прежней модели и 403 ограничения бесплатного тарифа для внешнего приложения. OpenRouter Ling/DeepInfra подтвердил валидное трёхкарточное чтение за14,36с. Подтверждённые квитанции тестов составляют $0.000175614; учёт с резервами запросов без квитанции $0.000825796. Общий тестовый бюджет владельца $5 сохраняется. Один успешный пример ещё не подтверждает качество всех чтений.

Разделы ниже фиксируют предыдущий этап планирования и предварительную проверку; актуальные результаты приведены выше и в `app/docs/PROVIDER_DIAGNOSTICS.md`.

## Подтверждено владельцем

- Действующих пользователей и оплаченных подписок нет. Совместимость с действующими подписками не ограничивает переделку; старые данные не удалять автоматически.
- Аудитория: женщины 25–40 лет.
- Ценность: ритуал, глубокий разбор вопросов, немного общения.
- Сохранить разновидности раскладов и проводников, их индивидуальность в характере и небольшие различия в дизайне.
- Допустима сильная авторская стилизация. Классическая колода и покупаемые визуальные варианты в будущем рассматриваются как возможное развитие, а не обязательный состав первого релиза.
- Доступный бюджет OpenRouter: $5. Для планирования принять как общий потолок тестов, пока не уточнено иное; расходы ещё не производились.
- Предпочтительно проверить возможность использования OpenCode Zen: ранее работал, сейчас пользователь сообщает об ошибках.

## Рабочие решения архитектуры

- Пересобрать frontend; серверное ядро переработать модульно, сохраняя проверенные части. Отсутствие пользователей позволяет свободнее изменить API и схему, но не оправдывает удаление данных без необходимости.
- Разделить семантическую колоду и визуальное оформление: card_id/значения/ориентации относятся к трактовке, deck_theme_id/asset_version — к изображению. Оформление не меняет результат выбора карт и смысл чтения. История фиксирует используемое оформление. Права на приобретённые варианты — отдельная сущность доступа, реализуемая позже.
- Первый релиз: вопрос → выбор расклада и проводника → раскрытие → подробное чтение → короткие уточнения → журнал. Количество уточнений и платные условия пока не утверждены.
- Общая палитра и композиция для всех проводников; различия через символ, небольшой акцент, речь и микродетали. Не выводить вкусовые предпочтения из возраста/пола аудитории без проверки.
- Общение привязать к исходному раскладу и сохранённому контексту. Не перетягивать карты незаметно при каждом уточнении. Свободный чат и долгосрочную память не считать частью первого релиза.
- Основной авторский стиль взять из приложенного чёрно-золотого референса. Сначала hero, рубашка, Луна, Шут и Отшельник; классический вариант и магазин колод могут появиться позже.
- Монетизацию и размеры квот назначать после измерения качества и себестоимости чтения с уточнениями; прежние цены не считать утверждёнными.

## Zen: предварительная проверка

В текущем коде основная модель `ling-3.0-flash-fin-free`, резервные `laguna-s-2.1-free` и `hy3-free`. На момент проверки все три отсутствуют в публичном ответе https://opencode.ai/zen/v1/models. Это подтверждённое расхождение конфигурации и текущего каталога, но не доказанная причина ошибки конкретного аккаунта.

Код использует endpoint chat/completions и x-session-id. Старый диагностический скрипт печатает только HTTP-статус, скрывая тело ошибки, поэтому не позволяет различить недоступную модель, проблему ключа и ограничение тарифа.

Официальная документация описывает API Zen и отдельные условия данных бесплатных моделей: https://docs.opencode.ai/docs/zen/. Наличие модели в публичном каталоге не гарантирует доступ для конкретного аккаунта или пригодность для работающего продукта. Нужен контролируемый запрос с серверным ключом и разбор фактической ошибки без раскрытия секретов. Такая проверка ещё не проводилась.

До проверки доступности, качества и условий Zen оставить дополнительным адаптером, не единственным источником чтений. Для тестов бесплатных моделей использовать вымышленные вопросы.

## Следующий этап

Подготовить спецификацию первого релиза и эталонный путь по трём картам с первым арт-паком. Отдельно подготовить ограниченную сравнительную проверку LLM: одинаковые вымышленные вопросы и карты, качество русского текста/голосов/синтеза, задержка и стоимость. Не запускать старый скрипт, который автоматически перебирает всю платную резервную цепочку без ограничения общего расхода.
