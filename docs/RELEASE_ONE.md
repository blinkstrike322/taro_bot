# ARCANUM — первый рабочий этап

13 октября 2026. Рабочий план реализации; цены, правила доступа и полный арт-пак ещё не утверждены.

## Продукт

Для женщин 25–40 лет: спокойный персональный ритуал, глубокое чтение по вопросу и несколько уточнений у выбранного проводника. Главная отвечает на один вопрос — как начать. Личность проводника проявляется в речи, символе и небольших деталях, сохраняя единый визуальный язык.

Сохранить восемь раскладов и трёх проводников. Для первого эталона подробно проверить расклад трёх карт. Карта дня — короткий вход, журнал — ценность при возвращении. Недельные/месячные представления, серия дней и статистика не занимают главную; их размещение решается после основного пути.

## Состав текущего этапа

1. Новый mobile shell, главная, форма вопроса, каталог раскладов, проводники.
2. Фиксация расклада через настоящий API, раскрытие карт, деталь, синтез.
3. Журнал с исходным сохранённым ответом; короткий вопрос по выбранной карте без новой тяги.
4. Восстановление черновика и существующего сеанса после перезагрузки, безопасный повтор begin.
5. Первый арт-пак: hero, рубашка, Луна, Шут, Отшельник. Остальные карты используют существующий арт; полный новый комплект не объявляется готовым.
6. Визуальный просмотр вне Telegram включается явно и использует только отдельные демонстрационные данные. Реальный режим не превращается в демонстрационный автоматически при ошибке API.
7. Усиление идемпотентности и обработки платежей, диагностика поставщика моделей.

## Чтение

Порядок: короткая главная мысль → каждая карта в своей позиции и ориентации → связь карт → практическая рефлексия. Текст привязан к вопросу. Проводник меняет язык, а не вытянутые карты.

Уточнение связано с исходным вопросом и картой. Не добавлять новую карту незаметно. Общий свободный чат, длительная память и новые платные квоты не входят в этот этап. Существующий API уточнений — исходная основа, в следующем этапе его контекст должен определяться сервером по session ID, а лимиты — сервисом доступа.

## Технические решения

- Существующий репозиторий, отдельная ветка `codex/arcanum-redesign` и worktree.
- Python/aiogram/aiohttp сохраняются; frontend пересобирается на существующих React/Next/TypeScript.
- Клиент создаёт и сохраняет ключ операции до POST begin. Сервер обеспечивает уникальность по пользователю, проверяет неизменность параметров и возвращает тот же результат при повторе.
- Карты и позиции фиксируются сервером. Статус готовности текста отделён от прогресса раскрытия в интерфейсе.
- GET-авторизация передаётся в заголовке; legacy URL-контракт поддерживается для совместимости.
- Платёж и доступ применяются атомарно; повтор charge ID не выдаёт доступ повторно.
- Полная сохраняемая очередь генерации, серверный retry, версионирование чтений и новый сервис доступа — обязательные последующие задачи перед релизом.
- Семантические карты отделяются от оформления. Для первого пакета mapping по стабильному card_id; полноценный deck_theme_id и права покупки позже.

## Приёмка текущего этапа

- Главная, настройка, три карты, деталь и журнал проходят путь на ширинах 320/390/430.
- Нет горизонтального переполнения, текст и touch targets читаемы, reduced motion работает.
- Визуальные эффекты не заставляют ждать доступного действия.
- Preview явно помечен, не использует ключи и не маскирует сбой реального API.
- Backend проверяет владельца и idempotency key; сценарии повторов покрыты тестами.
- Production не используется для разработки; локальный тестовый сервер не получает Telegram updates и не посылает уведомления.
- Отчёт о моделях содержит реальные ошибки и стоимость, без секретов.

## Не завершено этим этапом

Полная колода, цены и тарифы, новый checkout, сохраняемый worker с восстановлением после рестарта, качество чтения на большом наборе вопросов, память диалога, реальные Telegram iOS/Android, hosting/staging, бэкапы и release. Рабочий UI и зелёные тесты не означают готовый платный релиз.
