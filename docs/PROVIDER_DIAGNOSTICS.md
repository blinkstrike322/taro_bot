# Проверка провайдеров — 13 октября 2026

## Результат Zen

Бесплатный Zen сейчас **недоступен для запросов из таро-бота**: текущая бесплатная модель отвечает HTTP 403 с типом `FreeTierError` и прямо ограничивает использование приложением OpenCode. Замена модели не решает это ограничение. Заголовки клиента, сессии и обход через OpenCode не применялись.

Дополнительно старая основная модель бота снята с действующего каталога `/zen/v1/models` и возвращает HTTP 400: модель недоступна. Все три ID, зашитые в исходном коде (`ling-3.0-flash-fin-free`, `laguna-s-2.1-free`, `hy3-free`), отсутствовали в полученном каталоге. Это две разные причины отказа: устаревший ID и ограничение бесплатного тарифа.

Проверка выполнена локально в 01:09 по московскому времени. Секрет загружен из исходного локального `.env` программно; значения ключей не выводились и не копировались в репозиторий. Запросы содержали только вымышленный технический текст «Ответь одним словом: да», с лимитом 16 выходных токенов.

| Запрос | HTTP | Время | Результат |
| --- | --- | --- | --- |
| `GET /zen/v1/models` | 200 | 0,92 с | 83 модели; Ling 3.1 и MiMo V2.6 Flash Free присутствуют |
| `POST /zen/v1/chat/completions`, `ling-3.0-flash-fin-free` | 400 | 0,27 с | `server_error`: upstream сообщил, что модель недоступна |
| `POST /zen/v1/chat/completions`, `ling-3.1-flash-free` | 403 | 0,28 с | `FreeTierError`: бесплатный тариф разрешён только из OpenCode |

После явного отказа по типу приложения проверка остановлена. MiMo не вызывался. Новый `/inference/v1` не использовался как обход отказа. Платные модели Zen и OpenRouter не вызывались.

**Учёт:** 1 запрос каталога, 2 запроса completions, 0 успешных генераций, 0 платных запросов. Расход тестового бюджета OpenRouter — **$0 из $5**. Тестировавшиеся модели опубликованы как бесплатные; Zen не вернул токены/стоимость, баланс аккаунта не запрашивался.

## Источники и решение

[Официальная документация OpenCode Console](https://opencode.ai/v2/docs/console/models/) теперь указывает `/inference/v1` для прямого API, описывает API-ключи и временный характер бесплатных моделей. [Публичный каталог старого endpoint](https://opencode.ai/zen/v1/models) проверен прямым GET; каталог важнее статического списка ID в документации при определении текущей доступности. Документация отдельно указывает, что некоторые бесплатные модели могут использовать запросы для улучшения моделей, а NVIDIA free endpoints предназначены для испытаний. Это дополнительная причина выбирать production-модель отдельно от бесплатного технического теста.

Для платного продукта: один явно выбранный провайдер и основная модель, ограниченный список резервных моделей, измеряемая стоимость каждой генерации. Бесплатный Zen не считать рабочей зависимостью. Платный API OpenCode Console можно оценивать отдельно после выбора бюджета и тарифов; этот тест его доступность не устанавливал.

## OpenRouter: рабочий маршрут найден

После отдельного разрешения на узкую платную проверку выполнены **4 запроса completions** по двум конкретным моделям. Использованы только вымышленные вопросы, предварительная проверка актуальных цен и лимиты: не более $0,03 на запрос и $0,10 суммарно в сохраняемом локальном журнале. До сетевого запроса резервируется консервативная максимальная стоимость; отсутствие квитанции не обнуляет резерв. Общий бюджет пользователя $5 не менялся.

| Попытка | Результат | Время | Полученная стоимость |
| --- | --- | --- | --- |
| Mercury 2.5, три карты, JSON Schema | read timeout | 48,68 с | Квитанция не получена; сохранён резерв $0,00044056 |
| Ling 3.0 Flash, три карты, JSON mode по минимальной цене каталога | HTTP 404: нет совместимого endpoint | 0,39 с | Квитанция не получена; сохранён резерв $0,000209622 |
| Ling 3.0 Flash, одна карта, обычный текст с запросом JSON, лимит 800 токенов | HTTP 200, `finish_reason=length`; JSON не прошёл проверку | 3,65 с | $0,000054054, 174 входных + 800 выходных токенов |
| **Ling 3.0 Flash через DeepInfra, три карты, JSON mode, reasoning отключён** | **HTTP 200, валидный JSON, точные карты и позиции** | **14,36 с** | **$0,00012156, 436 входных + 530 выходных токенов** |

Причина Ling 404 установлена read-only проверкой endpoint metadata: каталог объединяет возможности разных провайдеров. Дешёвый Novita endpoint стоит $0,021/$0,063 за 1 млн входных/выходных токенов, но не поддерживает `response_format`. DeepInfra поддерживает JSON mode, однако стоит $0,06/$0,18. Ограничение цены дешёвым тарифом одновременно с обязательным JSON mode исключало оба endpoint. Это не отказ самой модели.

Последняя проверка использовала собственные цены и параметры **DeepInfra**: `provider.only=[deepinfra]`, без fallback провайдера, `provider.max_price={prompt:0.06, completion:0.18}`, `response_format=json_object`, `require_parameters=true`, `reasoning.enabled=false`. Лимит 3000 токенов обеспечивал запас, фактически понадобилось 530. Провайдер вернул `reasoning_tokens=0` и `finish_reason=stop`. JSON mode обеспечивает синтаксис; соответствие нашим полям, картам и позициям отдельно проверяется сервером. Это не подтверждение строгого JSON Schema режима для Ling.

В тесте на 800 токенов предыдущий результат был усечён. Причину расхода этих токенов нельзя уверенно назвать: содержимое reasoning той попытки не сохранялось. После отключения reasoning получен полный валидный ответ. Образец полезен для проверки интеграции, но одного вымышленного вопроса недостаточно для оценки индивидуальности проводников и качества платного продукта. В тексте есть языковая шероховатость («кругок»), поэтому редакторский контроль нужен отдельно от JSON-валидации.

**Финансовый учёт:** подтверждённые квитанциями расходы — **$0,000175614**. Сумма подтверждённых расходов и удержанных резервов — **$0,000825796**, то есть менее $0,001. Стоимость Mercury без квитанции не выдаётся за ноль. Агрегатное использование аккаунта между первой попыткой Mercury и следующей попыткой Ling выросло на $0,000243490; это согласуется с расходом Mercury, но без ID ответа нельзя точно связать прирост с конкретной генерацией.

Сохранены очищенные доказательства: `OPENROUTER_PROBE_MERCURY.json`, `OPENROUTER_PROBE_LING.json`, `OPENROUTER_PROBE_LING_RETRY.json`, `OPENROUTER_PROBE_LING_DEEPINFRA.json`. Последний файл содержит полный вымышленный вопрос в описании сценария выше и полученное чтение. API-ключи, содержимое `.env` и заголовки авторизации в файлах отсутствуют.

## Изменения runtime и дальнейшая проверка

- Zen отключён по умолчанию (`OPENCODE_ZEN_ENABLED=false`); наличие ключа не включает заведомо ограниченный бесплатный тариф. Автоматически придуманного `x-session-id` больше нет; явно заданная оператором легитимная сессия сохраняется.
- Основной и единственный автоматический маршрут — проверенный `inclusionai/ling-3.0-flash` через DeepInfra, reasoning отключён, цена ограничена проверенным тарифом.
- `OPENROUTER_MODELS` задаёт явный порядок моделей. Mercury остаётся разрешённым кандидатом только для сознательного добавления оператором; его последний тест не подтвердил готовность. Неизвестные ID игнорируются, случайного бесплатного роутера нет.
- Для чтений включён JSON mode с последующей серверной валидацией. Обычный текст уточняющих ответов сохраняет свой контракт.
- Узкая диагностика находится в `scripts/probe_providers.py`. Zen не вызывает платный fallback; OpenRouter требует `--provider openrouter --allow-paid`, разрешённые ID, цены и сохранённый бюджетный журнал. Локальные тесты контролируют отказ по типу клиента, секреты, бюджет и payload runtime.

Дальше требуется небольшая выборка вопросов для трёх проводников, повторные измерения скорости и оценка глубины чтений. Публикация и полноценный платный релиз этой проверкой не подтверждаются.
