# Система характеров проводников (v2): голос-ядро + память

Дата: 2026-09-14. Статус: approved, упрощённая приёмка — слепой тест.

## 1. Проблема

После рефактора Occult Terminal v3.1 (`ebabde9`) из `get_system_prompt()` вырезаны
persona/focus/moods/openers/voice_examples/forbidden (`core/moods.py`, `core/llm_gate.py`
удалены, `data/characters.json` ужата до 6 полей). Остался плоский system prompt +
длинный user prompt со схемой JSON и запретами (`core/prompts.py:149`
`del character_id` — персонаж в user prompt не упоминается вообще).
На слабых free-моделях схема перебивает персону → все три проводника звучат одинаково.
Старая система тоже была шаблонной: статичные 2 примера → сходимость к их паттерну
(Искра «вечно начинает с Серьёзно?»), `forbidden` — слабый негативный steering,
памяти о сказанном нет.

## 2. Цель и приёмка

Голоса различимы на слух; анти-шаблонность механизмом, а не надеждой.
Приёмка — **слепой тест**: один вопрос × три проводника (контент контролируем) +
один расклад «3 карты»; метки срезаны; зачёт — все попарные различения угаданы.
Регресс: весь `pytest` зелёный. Стоп-лист штампов — warn-лог, не gate.

## 3. Дизайн (подход A)

### 3.1 Ядро голоса (`data/characters.json`, на проводника)

Поля: `persona` (без зашитых имён собственных — имя подставляется шаблоном),
`diction` (словарь образов + анти-словарь), `rhythm`, `stance` (позиция к человеку),
`lens` (вопрос, который проводник всегда задаёт картам:
Странница — «где тут свет», Хранитель — «что делать руками»,
Искра — «где ты себе врёшь»), `taboo` (запрещённые ходы, позитивной формулировкой;
Искре явно запрещён скелет «риторический вопрос-упрёк в заходе» — наблюдавшийся провал),
`entries[]` (пул 5–6 заходов), `voice_pool[]` (пул 6 примеров intro+advice).
Имена проводников не меняются.

### 3.2 Память вместо ротации настроений

Два контура. (а) Per-user: последние 3–5 толкований этого юзера у этого же
проводника из таблицы `readings` (уже есть `user_id`, `character_id`,
`interpretation`) → их intro+advice уходят в `avoid_texts`. Нового хранилища нет;
новым юзерам блок пуст. (б) Ротация пула: на запрос сэмплируем 2 примера из
`voice_pool`, исключая использованные в последних N запросах (in-memory очередь;
бот однопроцессный; после рестарта деградация к случайным двум, не поломка).
Мудов-настроений нет.

### 3.3 Сборка промпта (порядок фиксирован)

персона-ядро → линза → 2 примера из пула → карты/вопрос → схема JSON →
**голос-напоминание последней строкой** (2 предложения в голосе, recency bias) →
стоп-правила (emoji/латынь). `del character_id` убрать: персонаж упоминается и в
user prompt. Блок «НЕ ДЕЛАТЬ» ужать до 3 пунктов. Схема JSON и валидация — без
изменений. Per-guide декодинг: Искра выше temperature + короче, Хранитель ниже +
сжато, Странница середина (константы в `core/llm.py`, рядом с `call_llm`).

### 3.4 Фразы интерфейса в голосе

Голос проводника там, где говорит персонаж: `WHISPERS` → три пула
(фронт тянет по `characterId`, фолбэк — нейтральный пул), `fallback_from_cards_db`
→ три шаблона переписать в голосе, `reminder_loop` → per-guide формулировки
неактивным, приветствия `handlers.py` → аудит под новые persona.
Нейтральными остаются: ошибки, paywall-механика, дисклеймеры.

## 4. Файлы

- `data/characters.json` — новые поля + все тексты (самый большой дифф).
- `core/prompts.py` — `get_system_prompt` (сборка ядра+линзы+примеров),
  `build_reading_prompt(..., character_id, voice_reminder)` — без `del`,
  сэмплирование пула с исключениями.
- `core/llm.py` — `interpret_reading(..., avoid_texts)`, per-guide
  temperature/max_tokens, голос-напоминание после схемы.
- `storage/db.py` — `get_recent_texts(db, user_id, character_id, limit)`;
  `app.py::_whisper_task` прокидывает `user_id` → память.
- `bot/handlers.py`, `core/reminder.py` — формулировки.
- `web/src/lib/guides.ts` + `transcript.ts` + `useGuide.ts` — per-guide WHISPERS.
- `tests/test_character_voice.py` — сборка промпта: порядок блоков, сэмплирование
  без повторов, пустая память, детерминизм при фикс. seed; per-guide temperature mapping.

## 5. Риски

- Слабые модели: промпт растёт (~+600–800 токенов) — компенсируем ужатым
  «НЕ ДЕЛАТЬ» и ядром вместо стены текста; примеры короткие.
- Temperature-игла: высокая T у Искры даёт разброс — в слепом тесте это плюс
  (живость), регресс держим структурой схемы, не тоном.
- In-memory очередь примеров сбрасывается рестартом — приемлемо (деградация мягкая).

## 6. Вне скоупа

Новые интерактивные механики (follow-up чат, ритуалы), визуал `guides.ts`
(уже даёт идентичность), новые эндпоинты/миграции БД, смена моделей.
## 7. Voice gate v2 (дополнение от 2026-09-14, после провала слепого теста v1)

Слепой тест v1 провален: все три проводника звучали Странницей («нити»,
«это не X, а Y»). Причина: модель сама приносит шаблоны (нитей не было
в примерах — это находка модели на вопросы про отношения), а отбора не было.
Решение — голос через отбор: `core/voice_gate.py` (slop-паттерны из stop-slop,
чужой лексикон на проводника, отпечатки голоса, схожесть с недавними),
best-of-3 с починкой в `interpret_reading` (`MAX_QUALITY_ATTEMPTS=3`,
порог `SCORE_PASS=85`), калибровка и регрессия в `tests/test_voice_gate.py`
(включая догфуд: все примеры voice_pool сами проходят гейт).
Промпт: компактное ядро + `PROMPT_SLOP_BAN` + чужие слова; схема single
больше не учит card-talk («означает», «в контексте» убраны из описаний полей).
