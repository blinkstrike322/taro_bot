# ARCANUM — перенос v5 в приложение

14 октября 2026. Реализация в ветке `codex/arcanum-redesign`, изолированная копия `app/`. Принятый макет v5 сохранён отдельно. Продакшен и исходная рабочая копия не изменены.

## Что перенесено

- Чёрная сцена из 12 логических слоёв, объединённых в три группы движения; локальные Forum и IBM Plex Mono. Цвет проводника меняет акцент, материал сцены остаётся самостоятельным будущим решением.
- Заставка на одну секунду при загрузке документа. Восстановление сеанса происходит под ней; переходы между экранами её не повторяют.
- Один ввод вопроса, выбор расклада в нижнем листе, восемь настоящих серверных схем, раскрытие сразу в чтение. Вертикальные точки вместо нижней панели управления картами.
- Обычная прокрутка текста. Новый жест на нижней границе ведёт вперёд, на верхней — назад. Левый жест возвращает к столу. Доступны точки, клавиатура и ненавязчивая подсказка-кнопка в конце главы. После последней карты — общее чтение и обсуждение в той же ленте.
- Календарь журнала с месяцами, отметками дней, фильтром и серверной историей. Три иллюстрированные персоны с характером и примером голоса; выбор только в четвёртой вкладке.
- Настройки движения и существующих напоминаний бота сохраняются. Звуковой движок, языки и покрытия не имитируются переключателями.
- Сервер сохраняет расклады, голос проводника, уточнения и ключи операций. Повтор после сбоя использует тот же набор карт. Повторная попытка занимает текущий период квоты, не меняя дату истории. Уточнения получают контекст расклада и шесть последних завершённых реплик из БД.

## Локальный запуск

`python scripts/dev_studio.py` запускает http://localhost:3210/ и API на loopback8097. Нужен Python с зависимостями проекта; команда для установленного окружения приведена в `docs/LOCAL_STUDIO.md`.

Студия использует реальные обработчики API, случайное вытягивание из78 карт и отдельную постоянную SQLite-базу, но подготовленные тексты. Внешний индикатор сообщает режим. Ошибки/задержки можно воспроизводить из него. Платные вызовы не выполнялись при этой реализации. Live-режим включается только явной командой с серверным ключом и лимитами, см. инструкцию студии.

- **274 pytest** пройдены, включая владение сеансами, параллельные повторы, сохранение вопросов, историю контекста, отказ справочного fallback, старый неудачный расклад/текущую квоту и изоляцию студии. Остались37 предупреждений прежних инфраструктурных API; это не ошибки тестов.
- **41 Vitest** пройден; TypeScript и ESLint изменённых компонентов/модулей пройдены. `next build --webpack` создаёт статический production-экспорт.
- В production JavaScript нет `/__studio/bootstrap` и `NEXT_PUBLIC_DEV_MOCK_INITDATA`. Публичный сервер не получает локальные маршруты студии.
- CUA: создание всех8 схем через UI, соответствующие завершённые записи в SQLite с1/1/3/3/3/6/6/7 картами; повтор карты дня возвращает ту же карту; выбор проводника переживает загрузку.
- CUA: прокрутка внутри главы не переводит её сама; отдельный жест у конца переводит вперёд; у начала — назад; левое перетаскивание карты возвращает к столу. После раскрытия всех карт общее чтение и вопрос проводнику доступны без отдельного перехода.
- CUA: обсуждение сохраняется после загрузки и открытия через журнал. Сеанс пережил перезапуск студии. Принудительный сбой дал явное состояние ошибки; повтор восстановил толкование того же Отшельника.
- CUA: настройки движения и уведомлений сохраняются после перезагрузки. Проверены пустой месяц, возврат в текущий и фильтр дня.
- Проводники:320/360/390/430px, горизонтального переполнения нет. «Подкова» проверена визуально на320px, «Пентаграмма» —360px, журнал —390px. Все78 URL изображений вернули200.
- Уточнение восстановления: обнаружены и исправлены смещение на86px из-за offsetParent и смещение от вертикальной анимации главы. Вход главы теперь растворяется без перемещения текста.

## Что ещё до выпуска

- Независимое SDD-ревью не состоялось: два запуска ревьюеров вернули лимит аккаунта. Выполнена самостоятельная проверка, она не заменяет независимую.
- Настоящие touch-жесты, экранная клавиатура и safe areas внутри Telegram iOS/Android ещё не проверены. Для чтения на SDK7.7+ отключается конфликтующий жест сворачивания Mini App; при выходе он включается обратно. Основание: [Telegram Mini Apps API](https://core.telegram.org/bots/webapps#initializing-mini-apps).
- Старт при недоступном API имеет сохранение назначения и кнопку повторного подключения; отдельный браузерный сценарий отключения только API пока не прогонялся.
- Системный reduced-motion обработан CSS; переключатель эффектов проверен. Проверки на реальном слабом устройстве, профилирование FPS и аудио — следующие этапы.
- Качество настоящих чтений, тарифы/лимиты уточнений, производственное восстановление длительных фоновых задач после аварии, Telegram Stars и релизная нагрузка требуют отдельной приёмки. В этой миграции не проводились новые платные оценки моделей.
- Полная авторская колода, звуки, локализация и независимые покрытия остаются дальнейшими этапами.
