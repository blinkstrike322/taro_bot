## Реализовано

- Новый мобильный интерфейс: главная, вопрос, выбор расклада/проводника, открытие карт, чтение по позициям и синтез, уточнение, журнал.
- Сохранены восемь типов расклада и три проводника. Новая палитра: уголь/олива, латунь, пергамент; лунный, латунный и медный акценты.
- Пять оригинальных ImageGen-ассетов, версии v001/v002, PNG masters и WebP; вторая версия применена к интерфейсу по уточнению о палитре Elden Ring.
- Реальный API используется по умолчанию. Preview вне Telegram включается явно и показывает только подготовленный пример трёх карт, с отдельным хранением.
- Черновик и ключ создания сохраняются до запроса. При потерянном ответе повтор возвращает тот же расклад; вопрос и проводник фиксируются до разрешения неопределённости.
- При reload клиент проверяет доступ к существующему сеансу на сервере и восстанавливает канонические карты/текст; прогресс раскрытия сохраняется локально.
- Уникальные idempotency keys в БД, защита от конкурирующих запросов, проверка неизменности входных данных; GET-авторизация в заголовке.
- Receipt и выдача доступа Stars атомарны. Генерация ограничена общим deadline, включающим активный HTTP и backoff.
- Подтверждён рабочий OpenRouter-маршрут Ling3.0Flash/DeepInfra. Бесплатный Zen выключен по умолчанию после фактического ограничения API.

## Проверено

- 263 серверных теста, Ruff и Mypy47files прошли.
- 34 имеющихся frontend unit-теста прошли; TypeScript, ESLint новых компонентов и production static build прошли.
- E2E проходит реальную цепочку UI→API→временная SQLite→сохранение→журнал. Только LLM в локальном тестовом сервере заменён фиксированным ответом. Telegram-поллинг, напоминания и реальные платежи не выполняются.
- Полный эталонный путь, искусственно потерянный ответ begin и безопасный повтор, reload с открытой первой картой, уточнение и сохранённый журнал.
- Восемь раскладов, правильное число карт1/3/6/7, выбор всех трёх проводников, раскрытие и чтение на320px.
- Главная/чтение на320/360/390/430px; всего24 проверки размеров, без горизонтального переполнения и сломанных изображений, без pageerror. Проверка reduced motion.
- Скрытый фронт карты исключён из accessibility tree до открытия.
- Реальный LLM smoke probe: валидный трёхкарточный JSON14,36с. Подтверждённый расход$0.000175614; сумма расходов и консервативных резервов$0.000825796. Один тест не доказывает качество всех чтений.

Артефакты: `docs/assets/premium/overview.png`, отдельные screenshots и `verification.json`. Прогоны: `scripts/serve_premium_test.py` и `scripts/premium_e2e.mjs`; Playwright требуется отдельно как dev-зависимость либо через переменные `PLAYWRIGHT_MODULE`/`PLAYWRIGHT_EXECUTABLE`. Тестовый API привязывается только к loopback, создаёт временную БД и не использует реальные ключи.

## Осталось до платного релиза

1. Сохраняемый worker и возобновление LLM после перезапуска сервера.
2. Отдельный статус базового fallback и согласованное правило возврата квоты.
3. Привязка уточнений к сеансу на сервере, лимиты и хранение диалога в БД. Сейчас API получает контекст выбранной карты от клиента, уточнения сохраняются только локально для активного сеанса.
4. Проверка качества и голосов на более широком наборе вопросов; резервный provider. Сейчас default — одна проверенная route.
5. Остальные75 иллюстраций, выбор темы колоды, окончательная художественная приёмка.
6. Новые тарифы, checkout и права доступа к дополнительным колодам; прежние цены не утверждены для нового продукта.
7. Настоящий staging-бот и Telegram iOS/Android, клавиатура и реальные safe areas, hosting, бэкапы и восстановление, наблюдаемость, запуск и откат.
